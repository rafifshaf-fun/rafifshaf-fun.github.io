Pipeline MLOps Saham Indonesia

Pipeline ML end-to-end yang dilengkapi experiment tracking, monitoring real-time, dan pelatihan ulang otomatis untuk prediksi saham Indonesia.

🔒 NDA · Demo Sederhana
MLflow Grafana Docker Scikit-learn Pandas Time Series Python 2023–2024

Masalah

Bursa Efek Indonesia (BEI) menghadirkan tantangan unik bagi model ML: tingkat volatilitas yang tinggi, karakteristik mikrostruktur pasar, dan pengaruh kalender regulasi yang tidak ditemui pada pasar Barat. Klien membutuhkan pipeline prediksi untuk menghasilkan sinyal BUY/SELL pada 45 saham blue-chip IDXBLUE. Selain menargetkan akurasi tinggi, sinyal yang dihasilkan wajib dapat dipantau, dilatih ulang, serta diaudit secara transparan.

Persyaratan utamanya: pipeline beroperasi penuh tanpa campur tangan manual, mulai dari penarikan data, pelatihan model, evaluasi performa, hingga deployment dengan observabilitas menyeluruh. Repository publik ini menampilkan demonstrasi arsitektur yang telah disederhanakan, sedangkan versi skala production terlindungi oleh NDA.

Mengapa Ini Sulit

  • Data time series keuangan bersifat non-stasioner: Dinamika pasar senantiasa berubah. Model yang bekerja optimal di kuartal sebelumnya bisa jadi tidak relevan di kuartal berjalan. Oleh karena itu, pipeline membutuhkan mekanisme deteksi drift otomatis dan pemicu retraining yang responsif.
  • MLOps efisien pada infrastruktur terbatas: Berjalan sepenuhnya di VPS standar menggunakan Docker Compose tanpa bergantung pada layanan cloud mahal seperti AWS SageMaker atau Databricks. MLflow, Grafana, dan layanan prediksi beroperasi berdampingan secara optimal.
  • Feature engineering skala besar: Data pasar domestik memerlukan fitur yang disesuaikan secara khusus: indikator rotasi sektor, perbandingan aliran dana asing dan domestik, serta penyesuaian kalender khusus (seperti dampak bulan Ramadhan terhadap volume perdagangan).
  • Keterauditan tinggi: Setiap keluaran prediksi keuangan harus dapat dipertanggungjawabkan. Riwayat setiap versi model, konfigurasi fitur, dan hasil prediksi tersimpan dengan rapi.

Tech Stack

  • Scikit-learn: Framework ML utama untuk pemodelan tren harga saham.
  • MLflow: Pengelolaan experiment tracking, model registry, dan manajemen deployment.
  • Grafana: Dasbor pemantauan real-time untuk akurasi prediksi, data drift, distribusi fitur, dan kesehatan server.
  • Docker + Docker Compose: Lingkungan alur kerja berbasis container yang terisolasi dan dapat direproduksi.
  • Pandas: Pemrosesan data, feature engineering, dan pembersihan data mentah.
  • Deteksi drift kustom: Pengujian statistik terhadap distribusi fitur guna memicu pelatihan ulang model secara otomatis.
  • FastAPI: Layanan API inferensi prediksi yang ringan dan cepat.

Apa yang Akan Saya Lakukan Berbeda

  • Menyiapkan feature store: Penggunaan Feast atau penyimpanan berbasis Redis dapat mencegah ketidaksesuaian fitur antara fase pelatihan dan fase serving.
  • Mengadopsi DVC untuk versi data: Melacak relasi antara dataset spesifik dan model yang dihasilkan sangat krusial; mengandalkan Git saja belum memadai.
  • Menerapkan shadow deployment: Menjalankan model baru pada mode shadow sebelum dipromosikan ke tahap production akan meminimalkan risiko kegagalan.
  • Mengeksplorasi model gradient boosting: XGBoost atau LightGBM berpotensi menangkap pola non-linear secara lebih presisi dibandingkan model Scikit-learn standar.

Pelajaran Utama

MLOps bukan sekadar urusan perkakas canggih, melainkan tentang kepastian reproduksibilitas dan tingkat kepercayaan. Ketika setiap prediksi memengaruhi keputusan finansial, Anda wajib mengetahui persis versi model yang digunakan, masukan data yang diproses, serta alasan di balik keputusan tersebut. Inilah standar utama dalam membangun sistem MLOps.
